Webhooks

Documentação da API

Endpoints disponíveis para integração

POST /api/webhook/pagamento – Notificações de pagamento
POST /api/webhook/usuario – Criação/atualização de usuários
POST /api/webhook/sessao – Eventos de sessão

Exemplo de Integração (cURL)

curl -X POST https://mstelecom-api.duckdns.org/api/webhook/pagamento \
  -H "Content-Type: application/json" \
  -d '{"evento":"pagamento.confirmado","cliente":"CLIENTE_NOME","valor":15.00,"mac":"XX:XX:XX:XX:XX:XX"}'
